# Tik Tak Toe Preview Video Production Package

Status: production package only. No preview video was rendered, uploaded, or faked in this pass.

This package is for a 24-27 second Google Play preview video using only real Tik Tak Toe gameplay footage captured from the current app.

## Package Files

- `shot-list.md`: approved timing, capture moments, edit notes, and real footage requirements.
- `captions.srt`: caption file for the approved script.
- `voiceover-script.txt`: optional voiceover script aligned to the approved timing.
- `youtube-play-checklist.md`: YouTube upload and Play Console checklist.

## Export Target

- Orientation: portrait 9:16.
- Recommended resolution: 1080 x 1920.
- Length: 24-27 seconds.
- Format: MP4, H.264 video, AAC audio.
- Audio: optional app sounds plus licensed/original background music only.
- Captions: include captions for muted autoplay and accessibility.
- Black bars: none.

## Real Footage Rule

Use real captured app footage for every gameplay shot. Do not animate, paint, composite, or edit in board marks, scores, result states, history rows, ads, or controls.

Allowed supporting visuals:

- `store_assets/feature_graphic/feature-graphic.png` may be used as a YouTube thumbnail reference or a very brief end-card support asset.
- `store_assets/app_icon/play-store-icon.png` may be used only as a small supporting brand element outside gameplay, not as a replacement for gameplay footage.

## Capture Gates

- Capture from package `com.childhood.tiktaktoe`.
- Capture current app UI only.
- Complete real rounds before capturing result or history states.
- Do not show ads.
- Do not show unavailable features: online multiplayer, leaderboard, shop, skins, login, cloud sync, rewards, tournaments, or multiple AI difficulties.
- Do not show hands, device frames, notifications, private data, or unrelated status-bar clutter.
- Keep actual in-game experience visible within the first 10 seconds.
- Keep at least 80% of the video representative of actual gameplay.

## Output Naming

Recommended final local export name after real capture and edit:

- `store_assets/preview_video/tik-tak-toe-play-preview.mp4`

Do not create or upload that final file until real footage capture and QA are complete.
