# Preview Video Package

This folder contains the production package for the Arrow Puzzle Google Play preview video.

- `production-package.md`: approved concept, capture rules, exact timeline, editing notes, upload checklist, and QA.
- `shot-list.csv`: editable shot list for capture/editing tools.
- `captions.srt`: caption timing for the 24-second preview cut.

No final MP4 has been rendered or uploaded. Capture real gameplay only, and keep ads disabled during capture.
