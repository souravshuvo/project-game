# Preview Video Package

This folder contains the Dew Bubble Garden Google Play preview video production package.

No final video is included yet because real gameplay capture was not approved and no captured clips exist in the repository.

Files:

- `production-package.md`: full capture, edit, upload, and QA plan.
- `shot-list.csv`: edit decision list with required clip filenames and timing.
- `captions-en.srt`: planned caption file for the 28-second edit.

Required before rendering:

1. Capture real app clips into `captures/`.
2. Confirm no misleading ad-free or offline-only text is visible unless production ads and analytics are disabled.
3. Render the final video from real captured footage only.
