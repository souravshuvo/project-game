# Privacy And Data Safety Draft

Signal Workshop v1 is designed as an offline game.

## Current Data Use

- No account creation.
- No login.
- No ads.
- No analytics SDK.
- No cloud sync.
- Local progress is stored on the device with shared preferences.

## Google Play Data Safety Draft

If the app remains as implemented here:

- Data collected: none transmitted off device by app code.
- Data shared: none.
- Data processed locally: level progress, completed levels, best moves left.
- Security practices: no user account or server data transfer.

Re-check this document before upload if any SDK, ads, analytics, crash
reporting, cloud sync, purchases, or network feature is added.
