## Full Description Outline

Larder Labels is an original offline triple tile match puzzle about clearing
small boards of pantry-style label tiles.

Study the board, choose free labels, and manage the 7-slot tray. Three matching
labels clear automatically. Some labels sit above others, so the order of taps
matters.

Current v1 features:

- Simple one-touch tile selection
- Five handcrafted offline levels
- Original placeholder pantry-label tile set
- Layered tiles with clear covered/uncovered rules
- 7-slot tray with automatic triple clearing
- Restart and session-only next-level flow
- No login, ads, shop, cloud sync, live events, or external services
