# Play Store Metadata Draft

## Title

Trail Arena

## Short Description

Steer, grow, and survive in a glowing offline trail arena.

## Full Description Outline

Trail Arena is an original offline arcade survival game where you guide a
glowing trail through a compact arena.

Current features:

- Offline single-player arena.
- Simple drag steering.
- Food collection, growth, score, and best score.
- Two simple offline bots.
- Pause, retry, and quick sessions.

No online multiplayer, login, shop, skins, leaderboard, cloud sync, or ads are
included in version 1.
