## Capture Steps

1. Use a real launched app session only after recording is explicitly approved.
2. Use portrait `1080 x 1920` or higher if available.
3. Disable notifications and clean the status bar before recording.
4. Do not show live or test ads. If an ad appears, retake the shot.
5. Start from the main menu and record the first 3 seconds with the menu clearly visible.
6. Select `Notebook Classic` for a balanced v1 match unless another preset is intentionally shown.
7. Start `Practice innings`.
8. Record the spinner idle state, tap-to-spin state, and tap-to-stop settle animation.
9. Record at least one real delivery result and the updated score HUD.
10. For the extras shot, record natural gameplay until a real `Wide` or `No-ball` appears. If this takes too long, replace that shot with a real scoreboard/HUD update and keep the text `Runs, wickets, extras`.
11. Return to menu and start `Target chase`.
12. Complete the first innings naturally, then capture the target/innings-break screen.
13. Open `Challenge ladder` and capture the real current challenge state.
14. Finish any match naturally and capture the final result panel with Restart visible.
15. Do not splice in mock UI, fake scores, fake challenge progress, or generated app screens.
