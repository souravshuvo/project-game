# Emoji Chor Police Preview Video Package

This folder contains the Prompt S5B production package for the Google Play preview video.

No final MP4 was rendered in this pass because real app recording was not approved and the repository does not contain gameplay footage. The package is ready for capture and editing once a real device or emulator recording pass is approved.

## Delivery Mode

- Mode: production package
- Target duration: 26 seconds
- Orientation: portrait 9:16
- Target render: 1080 x 1920, 30 FPS, H.264 MP4, AAC audio
- Source rule: real gameplay footage only

## Included Files

- `production-package.md` - full timeline, capture plan, editing notes, QA
- `shot-list.csv` - edit-friendly shot list
- `voiceover-script.md` - optional voiceover and caption-only variant
- `captions/emoji_chor_police_preview.srt` - subtitle timing
- `captions/emoji_chor_police_preview.vtt` - web caption timing
- `youtube-upload-checklist.md` - YouTube upload requirements for Play use
- `assets/brand/` - approved icon and feature graphic support assets

## Not Included

- No final video file
- No fake gameplay footage
- No generated UI footage
- No YouTube upload
- No emulator or device recording
